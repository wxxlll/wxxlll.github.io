定义

一维vector

二维vector

二维vector本质上是“元素为一维vector”的vector，即vector<vector< T >>。

常用操作

v[i] 下标访问，不检查越界 int x = v[2];
v.front() 返回第一个元素 int first = v.front();
v.back() 返回最后一个元素 int last = v.back();
v.size() 返回当前元素个数 size_t n = v.size();
v.empty() 判断是否为空 if (v.empty()) ...
v.push_back(val) 在末尾添加元素 v.push_back(10);
v.pop_back() 删除末尾元素 v.pop_back();
v.clear() 清空所有元素 v.clear();
v.insert(pos, val) 在迭代器 pos 前插入 val v.insert(v.begin()+2, 99);
v.insert(pos, n, val) 插入 n 个 val v.insert(v.end(), 3, 7);
v.erase(pos) 删除迭代器 pos 处的元素 v.erase(v.begin()+3);
v.erase(first, last) 删除区间 [first,last) 的元素 v.erase(v.begin()+1, v.begin()+4);
